Summary of Your Project
Peace's Vault is a well-structured Windows security application featuring:
Process monitoring with NtSuspendProcess for blocking apps/files
UI Automation for detecting blocked URLs in browsers
PBKDF2 PIN hashing with salt + pepper
TPM/DPAPI encryption for configuration storage
Intruder detection via webcam capture with Discord webhook alerts
Watchdog process for self-protection
Custom themed GUI with blur effects

1. Security Improvements
Table
Issue	Current	Suggested
